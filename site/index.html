Rogue

AOT-safe, source-generated CQRS and mediator for .NET. Free and MIT-licensed, for good.

Install

dotnet add package SkathIO.Rogue
dotnet add package SkathIO.Rogue.Abstractions   # interfaces only, for library authors

Why Rogue

  • Source-generated dispatchRoslyn generates the dispatch code. Nothing is resolved by reflection at runtime.
  • Native AOTReflection-free, so it works with Native AOT and trimming.
  • Zero allocation on the hot pathA ValueTask-based pipeline keeps Send cheap.
  • Pipeline behavioursOpen generic behaviours, ordered with [BehaviorOrder].
  • StreamingStream requests return IAsyncEnumerable<T>.
  • From MediatR in one lineA compatibility shim and a migration guide.
